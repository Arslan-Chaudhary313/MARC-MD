## <img src="https://img.shields.io/badge/⌘-COMMON%20COMMANDS-F5B301?style=flat-square&labelColor=0d0d0d" height="28"/>

<sub>Common commands to deploy on any <b>VPS</b>, <b>Terminal</b> or <b>Termux</b>.</sub>

<br/>

### 📱 Termux
```bash
pkg update && pkg upgrade -y
pkg install git nodejs -y

```
### 🖥️ VPS / Ubuntu
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install git nodejs npm -y

```
### 📦 Clone & Install
```bash
git clone [https://github.com/YOUR-USERNAME/MARC-MD](https://github.com/YOUR-USERNAME/MARC-MD)
cd MARC-MD
npm install

```
### 🚀 Run & Keep Alive
```bash
npm start
# 24/7 with PM2
npm i -g pm2
pm2 start index.js --name marc-md

```
| Command | Purpose |
|---|---|
| git pull | 🔄 Update to latest version |
| pm2 logs marc-md | 📜 View live logs |
| pm2 restart marc-md | ♻️ Restart the bot |
| pm2 stop marc-md | ⏹️ Stop the bot |
